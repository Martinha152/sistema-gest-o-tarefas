# Sistema de Gestão de Tarefas

## Descrição do projeto
Este projeto foi desenvolvido como atividade acadêmica da disciplina de DevOps, com o objetivo de praticar o controle de versão e o trabalho colaborativo utilizando Git e GitHub.

A aplicação apresenta uma interface web simples com telas de login e cadastro de usuários. As funcionalidades atuais são demonstrativas e não utilizam autenticação real ou banco de dados.

## Tecnologias utilizadas
- HTML: estrutura das páginas.
- CSS: estilização e aparência visual.
- JavaScript: interatividade e comportamento dos formulários.
- Git: controle de versões do projeto.
- GitHub: colaboração e gerenciamento do código.

## Organização do projeto
- index.html: estrutura das telas.
- style.css: estilos visuais.
- script.js: funcionalidades em JavaScript.

## Trabalho colaborativo
O desenvolvimento é organizado em branches individuais. As contribuições são registradas por commits e encaminhadas por Pull Requests para revisão e aprovação antes da integração à branch principal.

## Finalidade acadêmica
Projeto elaborado para a Atividade 01 de DevOps — Controle de Versão.
